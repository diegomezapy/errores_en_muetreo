# 🎯 Errores Recurrentes en Tamaño Muestral

Presentación interactiva para congreso sobre errores metodológicos en cálculo de tamaño muestral.

## ✨ Características
- ✅ Diseño completamente responsive
- ✅ Animaciones CSS avanzadas
- ✅ Gráficos interactivos con Chart.js
- ✅ Fórmulas matemáticas con MathJax
- ✅ Efectos de zoom y transiciones
- ✅ Simulación de muestreo en tiempo real
