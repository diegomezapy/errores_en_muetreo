Error 1: Aplicación indebida de fórmulas de muestreo probabilístico

n = Z²p(1-p)/d²
n: tamaño de muestra
Z: valor crítico (ej. 1,96 para 95%)
p: proporción esperada
d: margen de error tolerado
najustada = n₀·N/(n₀ + (N-1))
n₀: tamaño muestral inicial
N: tamaño poblacional
Aplicable cuando: n₀ > 5-10% de N
check_circle Ámbitos de validez
  • arrow_rightMuestreo aleatorio simple (MAS)
  • arrow_rightMuestreo estratificado con selección aleatoria
  • arrow_rightCada unidad tiene probabilidad conocida y distinta de cero
error Problema metodológico
Se aplica la fórmula en estudios con muestreo no probabilístico (conveniencia, bola de nieve, auto-selección). Un n calculado correctamente no garantiza validez si el procedimiento de selección es incorrecto.
