Bienvenida

Es un honor darles la más cordial bienvenida al Congreso Latinoamericano de Sociedades de Estadística (CLATSE 2025), que se llevará a cabo del 20 al 24 de octubre de 2025 en la Pontificia Universidad Católica del Ecuador (PUCE), sede Quito.

Este congreso reúne a destacados especialistas, docentes, investigadores y profesionales de la estadística, la ciencia de datos y áreas afines, con el propósito de enriquecer y fortalecer la práctica estadística en Latinoamérica a través del intercambio académico, la investigación aplicada y la innovación.

En nombre del Comité Organizador y de la Sociedad Ecuatoriana de Estadística (SEE), agradecemos profundamente su compromiso y entusiasmo. Sus aportes serán fundamentales para el éxito de este encuentro académico.

Detalles de la Base de Muestreo

Base Real para el Desarrollo del Muestreo

El estudio se basó en datos recopilados de múltiples fuentes para garantizar la representatividad y validez estadística:

Fuentes de datos

  • Encuestas nacionales de salud y nutrición (ENSANUT)
  • Registros administrativos del sistema de salud público
  • Datos censales del Instituto Nacional de Estadística y Censos (INEC)
  • Estudios longitudinales de cohortes regionales

Características de la muestra

  • Tamaño muestral: n = 2,500 participantes
  • Diseño muestral: Muestreo estratificado por regiones
  • Periodo de recolección: Enero 2023 - Diciembre 2024
  • Criterios de inclusión: Adultos entre 18-65 años, residentes permanentes

Variables principales

  • Variables sociodemográficas (edad, género, educación, ingresos)
  • Indicadores de salud (IMC, presión arterial, condiciones crónicas)
  • Factores de riesgo (tabaquismo, actividad física, alimentación)
  • Acceso y utilización de servicios de salud

Consideraciones metodológicas

Se aplicaron factores de expansión para ajustar por no respuesta y para hacer inferencias a la población objetivo. El error muestral estimado es del ±2.5% con un nivel de confianza del 95%.

Implementación en R

Gestión de Datos y Simulación

Paquetes utilizados

  • dplyr y tidyr para manipulación de datos
  • ggplot2 para visualización
  • survey para análisis de datos complejos
  • boot para métodos de bootstrap
  • MASS para simulaciones

Código para gestión de datos

# Cargar librerías necesarias
library(dplyr)
library(tidyr)
library(ggplot2)

# Cargar y limpiar datos
datos <- read.csv("datos_estudio.csv")
datos_limpios <- datos %>%
  filter(edad >= 18 & edad <= 65) %>%
  mutate(imc_categoria = case_when(
    imc < 18.5 ~ "Bajo peso",
    imc >= 18.5 & imc < 25 ~ "Normal",
    imc >= 25 & imc < 30 ~ "Sobrepeso",
    imc >= 30 ~ "Obesidad"
  ))

# Análisis descriptivo
resumen <- datos_limpios %>%
  group_by(region, imc_categoria) %>%
  summarise(
    n = n(),
    promedio_edad = mean(edad),
    .groups = 'drop'
  )

Código para simulación

# Función para simular datos
simular_datos <- function(n, media, desviacion) {
  set.seed(123) # Para reproducibilidad
  rnorm(n, mean = media, sd = desviacion)
}

# Simulación de presión arterial
presion_sistolica <- simular_datos(1000, 120, 15)
presion_diastolica <- simular_datos(1000, 80, 10)

# Crear dataframe simulado
datos_simulados <- data.frame(
  id = 1:1000,
  presion_sistolica = presion_sistolica,
  presion_diastolica = presion_diastolica
)

# Análisis de datos simulados
resultados_simulacion <- datos_simulados %>%
  mutate(
    hipertension = ifelse(presion_sistolica >= 140 | presion_diastolica >= 90, 1, 0)
  ) %>%
  summarise(
    prevalencia_hipertension = mean(hipertension) * 100
  )

Consideraciones técnicas

Todo el código fue desarrollado en R versión 4.2.1 y está disponible en el repositorio GitHub del proyecto. Se implementaron controles de calidad de datos y validaciones cruzadas para garantizar la robustez de los resultados.
